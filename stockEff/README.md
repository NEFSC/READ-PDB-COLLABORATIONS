# READ-PDB-COLLABORATIONS: stockEff

This sub-directory contains functions to interface with stockEff. 

| File | Description | Initial Contributor |
| ---- | ----------- | ------------------- |
| borrow_ages.R | Function defines age borrowing procedure to develop ALKs using fillCF.R | Amanda Hart |
| calcIndex.R | Function replicates stockEff biomass and abundance survey index calculations.  | Amanda Hart |
| export_stock_specs_dynamic | Function that pulls current stockEff specifications into an .xlsx file for easy review | Dan Hennen |
| fillCF.R | Function fills CF specification template for stockEff | Amanda Hart, updates by Dan Hennen, Sam Truesdell, stockEff team |
| fillOB.R | Function fills OB specification template for stockEff | Amanda Hart | 
| read_stockEff.R    |  Function reads CSV files from stockEff and stores as an RData list. | Amanda Hart |
|      |             |                     |
